PROBLEMAS QUE SE CORRIGIERON
----------------------------
1. Excel de Policía: el encabezado está en la FILA 11, no en la 0.
   Las columnas salían como "Unnamed" porque se leía mal.
2. DANE devolvía HTTP 401: faltaba User-Agent de navegador.
3. Streamlit Cloud: faltaba requirements.txt en la RAÍZ del repo.
4. Estructura de anexos DANE: bloques por departamento + fila
   "Tasa de Desocupación (TD)".

ARCHIVOS A SUBIR A GITHUB (raíz del repositorio)
------------------------------------------------
  app.py
  data_pipeline.py
  requirements.txt
  README.md          (opcional)

STREAMLIT COMMUNITY CLOUD
-------------------------
1. Sube los archivos a un repo de GitHub (todos en la raíz).
2. En share.streamlit.io crea la app apuntando a app.py.
3. Si dice "Faltan dependencias":
     - Confirma que requirements.txt está en la raíz.
     - Manage app → Reboot.
   NO instales paquetes con pip dentro de app.py.

USO LOCAL
---------
  pip install -r requirements.txt
  streamlit run app.py
